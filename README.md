### [Mocato](https://mocato.vercel.app/) is a modern, lightweight Tailwind template designed for radio stations, podcasts, and audio-focused websites.    

The template includes a built-in radio player and is optimized for easy customization and quick deployment on platforms like Vercel.

- Tailwind CSS v4
- 100% Responsive Design
- Integrated Radio Player for live streaming or audio playback
- Clean & Minimal UI
- SEO-Friendly Markup
- Vercel Ready
